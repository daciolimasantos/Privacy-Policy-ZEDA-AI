# ZEDA AI GitHub Pages Website

## Como publicar

1. Crie um repositório no GitHub chamado, por exemplo:

```text
zeda-ai-site
```

2. Faça upload de todos estes arquivos na raiz do repositório:

```text
index.html
privacy.html
styles.css
assets/icon.png
README_GITHUB_PAGES.md
```

3. No GitHub, vá em:

```text
Settings → Pages
```

4. Em "Build and deployment", selecione:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

5. Clique em Save.

6. Aguarde o GitHub gerar o site.

O link ficará parecido com:

```text
https://SEU_USUARIO.github.io/zeda-ai-site/
```

A política de privacidade ficará em:

```text
https://SEU_USUARIO.github.io/zeda-ai-site/privacy.html
```

## Link para colocar no Google Play Console

Use especificamente o link do `privacy.html`.

## Importante

Antes de enviar ao Google, abra o link em uma aba anônima e confirme que a página carrega publicamente sem login.
